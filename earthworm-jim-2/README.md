# 🪱 Earthworm Jim 2 — играбельный прототип

Браузерный платформер на HTML5 Canvas с фирменными механиками Червяка Джима,
**рисованными персонажами и пятью злодеями-боссами**. Концепты уровней взяты из
скриншотов оригинала (`concepts/`). Историю добавим позже — сейчас главное механика,
графика и бои.

## ▶ Как играть
Открой сайт и нажми **ИГРАТЬ** (или подними локальный сервер из корня репозитория):
```bash
python3 -m http.server 8000
# http://localhost:8000/earthworm-jim-2/
```
Работает на клавиатуре и на тач-экранах. В меню есть экран **«Персонажи»** с
рисованным ростером героев, помощников и злодеев.

## 🎮 Управление
| Клавиши | Действие |
|---|---|
| `← →` / `A D` | Бег |
| `Space` / `Z` | Прыжок (отпустишь раньше — ниже прыгнешь) |
| `Space` в воздухе (держать) | 🚁 **Вертолёт** — медленное падение |
| `J` / `X` | 🔫 **Плазменный бластер**; держи для **мега-плазмы** |
| `K` / `C` | 🪢 **Голова-хлыст**; рядом с крюком — **зацеп и раскачивание** |
| `W` / `↑` | Лезть вверх по слизи · целиться вверх |
| `↓` / `S` | 🟢 **Снотт-парашют**; у зелёной стены — **прилипнуть** |
| `Esc` / `P` | Пауза · `M` — звук |

## 🧬 Механики
- Бег/прыжок с инерцией, coyote-time и буфером прыжка.
- Плазма + заряжаемая мега-плазма, патроны и авто-перезарядка.
- Голова-хлыст, вертолёт, крюки с маятниковой раскачкой.
- Снотт: прилипание к слизи, подъём, вытаскивание наверх, парашют.
- Питер Паппи бежит рядом и ускоряет восстановление патронов.
- Предметы: червячки (100 → +жизнь), патроны, здоровье, доп. жизнь.
- Шипы, лава/кислота, пропасти, жизни, чекпоинт по последней твёрдой точке.
- Параллакс-фоны, частицы, тряска, синтезированный звук.

## 👹 Уровни и злодеи
1. **Anything But Tangerines** — разминка + босс **Evil the Cat**: прыжки и клубки-снаряды.
2. **Villi People** — слизь и Снотт + босс **Major Mucus**: кислота сверху и призыв летунов.
3. **See Jim Run — Psy-Crow** — арена **Псай-Ворона**: пикирование и прицельный огонь.
4. **La Planeta de Agua — Bob** — underwater-арена **Боба**: веер пузырей из робо-аквариума.
5. **Insectika — Queen** — финал против **Королевы Слизней**: кислотные веера, призыв воронов, ударная волна.

Выход с уровня открывается только после победы над боссом.

## 🎨 Графика
- Игровые спрайты: `art/sprites/` — Джим (включая 4 кадра бега), Псай-Ворон, Кот Зло,
  Боб, Майор Слизь, Королева, Питер Паппи, Снотт.
- Рисованный фон свалки: `art/bg-junk.jpg`; остальные фоны дорисованы кодом.
- Исходники генерации: `art/raw/`, сборка прозрачных PNG: `tools/build_art.py` (Pillow).

## 📁 Структура
```
earthworm-jim-2/
├── index.html      # экраны, HUD, ростер, тач-кнопки
├── style.css       # оформление
├── levels.js       # 5 уровней + темы-палитры
├── game.js         # движок, боссы, спрайты, рендер, звук, UI
├── smoke.test.js   # headless-тесты
├── art/            # готовые спрайты, фон, raw-исходники, manifest.json
├── tools/          # сборка арта
└── concepts/       # скриншоты-концепты
```

## 🧪 Тесты
```bash
node smoke.test.js   # 26 проверок + soak на 6000 случайных кадров
```
Проверяются механики, все 5 боссов, открытие выходов, наличие арт-ассетов,
подбор предметов, лава и стабильность симуляции.
