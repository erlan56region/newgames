# 🪱 Червяк Джим — Earthworm Jim (1994)

Иллюстрированный фанатский справочник по **первой** игре Earthworm Jim (Shiny Entertainment, 1994):
скриншоты всех миссий + сколько персонажей, врагов/боссов, оружия, помощников и транспорта.

## ▶ Как открыть
Открой `index.html` в браузере (страница полностью автономна — все картинки лежат в `assets/`).
Либо подними локальный сервер из этой папки:

```bash
python3 -m http.server 8000
# затем открой http://localhost:8000/
```

## 🗺️ Порядок миссий
1. **New Junk City** — Билли-Бак / Чак
2. **What the Heck?** — Снеговик Расти / Кот Зло
3. **Down the Tubes** (+ Tube Race) — Боб / №4
4. **Snot a Problem** — Майор Слизь
5. **Level 5** (+ Who Turned Out the Lights?) — Робо-Цыплёнок
6. **For Pete's Sake** — защита Питера Паппи
7. **Intestinal Distress** *(Genesis / Special Edition / HD; нет на SNES)* — Док Двенадцатиперстной
8. **Buttville** — Королева Слизень-с-Задом (финал)
- ★ **Andy Asteroids?** — космическая гонка на Pocket Rocket против Psy-Crow (между мирами)
- ＋ **Big Bruty** *(Special Edition / HD)* — погоня-монстр после What the Heck?
